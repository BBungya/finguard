# 이상거래 탐지 평가 명세

[분할 설정](../configs/ml_split.toml)의 기간과 [Sparkov v1 파일 해시](../data/manifests/sparkov_evaluation.json)를 모든 모델 비교에 사용합니다. 2019년 거래로 모델과 전처리를 학습합니다. 2020년 상반기에 모델 설정과 탐지 기준 점수를 정한 뒤 고정하고, 하반기 거래로 최종 성능을 측정합니다. 기간별 거래 수와 사기 비율은 [분포 보고서](../reports/ml_split_distribution.md)에 있습니다.

## 하루 조사 한도

데모 기준은 하루 **20건**입니다. 검증 기간의 하루 거래량 중앙값 2,033건 중 약 1%에 해당합니다. 조사 여력이 다를 때 결과가 얼마나 바뀌는지 보기 위해 **10·50·100건**도 비교합니다. 이는 합성 데이터에 적용하는 가정입니다.

- 원본 거래 시각의 날짜별로 위험 점수가 높은 순서대로 정렬합니다. 점수가 같으면 거래 시각이 빠른 순, 거래 시각까지 같으면 거래 ID의 문자열 오름차순으로 정합니다.
- 하루에 상위 B건을 선택합니다. 하루 거래가 B건보다 적으면 있는 거래만 선택하고, 남은 한도는 다음 날로 넘기지 않습니다.
- 당일 거래의 점수를 모두 모아 비교하는 평가입니다. 각 점수는 해당 거래 시점까지 알 수 있는 정보로 계산합니다.

## 지표 계산

| 지표 | 계산 방법 |
| --- | --- |
| AP (평균 정밀도) | 기간 전체 거래를 위험 점수로 순위화합니다. 같은 점수는 한 그룹으로 처리하고, 탐지 기준을 내릴 때마다 늘어난 재현율에 그때의 정밀도를 곱해 합산합니다. |
| 혼동행렬 | 고정한 탐지 점수 이상을 조사 대상으로 보고, 실제 사기 여부와 대조해 TP(잡은 사기), FP(조사한 정상), FN(놓친 사기), TN(통과한 정상)을 셉니다. |
| Precision / Recall | 점수 기준에서 정밀도는 TP ÷ (TP + FP), 재현율은 TP ÷ (TP + FN)입니다. |
| Precision@B | 매일 상위 B건에서 잡은 사기 건수의 합 ÷ 실제로 선택한 거래 건수의 합입니다. |
| Recall@B | 매일 상위 B건에서 잡은 사기 건수의 합 ÷ 기간 전체 사기 거래 건수입니다. |

분모가 0이면 해당 지표는 미정으로 표시합니다. 일별 비율의 단순 평균 대신 기간 전체의 합으로 계산하며, 사기가 없던 날도 조사한 건수에 포함합니다.

예를 들어 하루 상위 20건 중 사기가 5건이고 그날 전체 사기는 10건이라면, 그날 **Precision@20은 25%, Recall@20은 50%**입니다. 학습에 없던 카드의 지표도 별도로 보고합니다. 전체 거래에서 선택한 조사 대상과 고정 점수 기준을 그대로 사용해 해당 카드의 결과를 집계합니다.

## 비용 가정과 탐지 점수 기준

조사 1건에 **1비용 단위**, 사기 1건을 놓치는 데 **10비용 단위**를 가정합니다. 놓친 사기 비용을 5와 20으로 바꾼 경우도 함께 계산합니다. 이 단위는 데모의 비교 기준입니다. 거래 금액이나 실제 손실액으로 환산하지 않습니다.

```text
가정 비용 = 조사한 거래 건수 × 조사 비용 + 놓친 사기 건수 × 미탐 비용
```

조사 건수에는 사기와 정상 거래가 모두 들어갑니다. 예시에서 상위 20건을 조사해 사기 5건을 놓쳤다면 가정 비용은 `20 × 1 + 5 × 10 = 70`입니다.

탐지 점수 기준은 검증 구간에서 기본 비용이 가장 낮은 값을 고릅니다. 서로 다른 관측 점수와 전부 제외하는 경우를 후보로 보고, 비용이 같으면 더 높은 기준을 선택합니다. 이 기준의 최종 테스트 결과와 하루 상위 B건의 최종 테스트 결과를 각각 기록합니다. 비용 5·20과 다른 조사 한도는 민감도 비교에 사용합니다.
