# 카드 이력 추가와 XGBoost 튜닝

[기준선](baseline.md)에서 쓴 데이터와 시간 분할, 하루 20건 조사 한도로 비교했습니다. 2019년 거래로 모델을 학습하고, 2020년 상반기에서 후보를 골랐습니다. 하반기의 기존 테스트 구간은 기준선과 같은 조건에서 결과를 비교하는 데 사용했습니다.

## 비교 방법

1. 랜덤포레스트와 XGBoost 각각에 #4의 카드 이력 네 가지를 추가했습니다. 최근 1시간·7일 거래 건수, 최근 7일 평균 금액, 표준편차입니다. 모델 설정은 [기준선 설정](../configs/baseline.toml)을 사용했습니다.
2. 이력을 추가한 XGBoost에서 트리 깊이 3·5·7을 비교했습니다. 깊이 5에서 학습률 0.05와 트리 200개를 함께 적용한 경우도 비교했습니다. [튜닝 설정](../configs/history_tuning.toml)에 변경값을 기록했습니다.
3. 검증에서 하루 상위 20건으로 가장 많은 사기를 찾은 후보를 선택했습니다. 동률이면 평균 정밀도(AP)가 높은 후보를 우선했습니다. 고정 점수 기준은 [평가 명세](../docs/ml_evaluation.md)의 비용 가정으로 검증 기간에서 각각 정했습니다.

같은 카드의 앞선 거래만 이력에 반영합니다. 거래 시각이 같으면 원본의 행 순서를 사용합니다. 학습에서 검증, 검증에서 테스트로 넘어갈 때도 앞선 거래 이력을 이어 쓰며, 사기 라벨은 이력에 들어가지 않습니다. 이력이 없으면 금액 평균과 표준편차를 모델 입력에서 `-1`로 표시합니다. 이력이 1건이면 표준편차 0을 그대로 사용합니다. [이력 피처 규칙](../docs/history_features.md)

## 상반기 검증에서 후보 선택

| 후보 | 하루 20건으로 찾은 사기 | AP |
| --- | ---: | ---: |
| 랜덤포레스트 기준선 | 1,859 | 0.8174 |
| 랜덤포레스트 + 이력 | 1,935 | 0.8752 |
| XGBoost 기준선 | 1,872 | 0.8328 |
| XGBoost + 이력, 깊이 5 | 2,028 | 0.9304 |
| XGBoost + 이력, 깊이 3 | 1,991 | 0.9045 |
| **XGBoost + 이력, 깊이 7** | **2,056** | **0.9429** |
| XGBoost + 이력, 깊이 5·학습률 0.05·트리 200개 | 2,046 | 0.9392 |
| XGBoost + 이력, 깊이 7·학습률 0.2·트리 100개 | 2,050 | 0.9442 |

깊이 7·학습률 0.1·트리 100개를 선택했습니다. 같은 깊이와 트리 수에서 학습률 0.2의 AP가 더 높았고, 학습률 0.1은 하루 20건 기준으로 사기를 6건 더 찾았습니다. 구간별 오류, 점수 보정 수준과 한 건 추론 시간은 [모델 카드](../docs/fraud_model_card.md)에 정리했습니다.

## 하반기 비교

| 모델 | 10건에서 찾은 사기 | 20건에서 찾은 사기 | Precision@20 | Recall@20 | 50건에서 찾은 사기 | 100건에서 찾은 사기 | AP |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 랜덤포레스트 기준선 | 1,141 | 1,536 | 41.74% | 76.34% | 1,814 | 1,914 | 0.7521 |
| 랜덤포레스트 + 이력 | 1,171 | 1,592 | 43.26% | 79.13% | 1,824 | 1,877 | 0.8098 |
| XGBoost 기준선 | 1,131 | 1,561 | 42.42% | 77.58% | 1,858 | 1,933 | 0.7729 |
| XGBoost + 이력, 깊이 5 | 1,206 | 1,691 | 45.95% | 84.05% | 1,921 | 1,964 | 0.8781 |
| **XGBoost + 이력, 깊이 7** | **1,233** | **1,711** | **46.49%** | **85.04%** | **1,940** | **1,977** | **0.8950** |

하루 20건에서 XGBoost는 이력 추가로 사기 130건을 더 찾았고, 깊이를 7로 바꾸자 20건을 더 찾았습니다. 랜덤포레스트는 이력 추가로 56건을 더 찾았지만, 하루 100건에서는 37건을 덜 찾았습니다.

검증에서 고른 점수 기준을 그대로 적용했을 때, 깊이 7은 3,042건을 조사해 1,822건의 사기를 찾았습니다. 깊이 5는 2,744건을 조사해 1,764건을 찾았습니다. 이 고정 기준에서는 깊이 5의 조사 정밀도가 64.29%로 깊이 7의 59.89%보다 높았습니다. 학습에 없던 카드의 사기 151건 중 하루 20건 기준으로 깊이 7은 140건, XGBoost 기준선은 128건을 찾았습니다. 이 카드 그룹의 모든 거래가 사기 라벨이므로 정상 거래의 판정 성능은 확인할 수 없습니다.

하반기 비교는 이전 기준선에서 사용했던 합성 데이터입니다. 후보는 상반기에서 골랐으며, 새 데이터에 대한 일반화는 별도로 검증해야 합니다.

## 다시 실행하기

```sh
uv run --locked --group ml python tools/tune_history_models.py
```

실행하면 `artifacts/history_tuning/`에 선택한 모델, 전처리기, 후보별 검증 지표와 비교 모델의 테스트 지표를 저장합니다. 환경과 기본 난수 시드는 기준선과 같습니다. 학습 데이터와 모델 파일은 Git에서 제외합니다.
